# V15.3 Device QA — Change Set

Only two production files changed from V15.2:

1. `index.html`
   - The secondary hero CTA now has the `secondary` class so mobile shows one primary CTA.

2. `css/mobile.css`
   - Added final canonical mobile rules so older responsive fragments cannot override V15.
   - Restored 12px product swipe gap and intended smart crops.
   - Added dedicated 821–1100px tablet mode.
   - Tablet uses hamburger navigation while keeping the desktop cinematic story.
   - Added short-landscape tablet/small-laptop tuning.

## Breakpoints

- `≤ 820px`: adaptive mobile experience
- `821–1100px`: tablet experience
- `> 1100px`: full desktop experience

For an existing V15.2 GitHub Pages deployment, replacing just `index.html` and `css/mobile.css` is sufficient.
